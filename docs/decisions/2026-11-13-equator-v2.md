# 赤道 2.0 适配

业务来源：用户 2026-11-13 确认的交互样例和主数据 Sheet 选择。PRD 为 Waymerce-PRDs/FIS/v2，用户已授权按讨论稿实现。

- 新增 `fis.xlsx.equator` 与 `fis.services.equator`，仅新版 50 列“模版”输入启用；旧版继续原引擎。
- 三个辅助 Sheet 的参考数据提取为 `assets/equator-catalog.json` 随程序内置，不复制领星客户发票到仓库，不迁移或覆盖旧主数据。
- 原两列映射入口复用。新版代码写短码，地址由新字典匹配。
- 客户编码默认用户确认的名称，允许修改。客户单号 B 列按用户验收反馈修正为该明细所属的 FBA 主单号，同货件各行重复该号，不复制源文件拼接列表；页面预览与导出一致。
- 新版渠道记忆键为 `equator_channel:<short-code>`，选择即保存，隔离旧版成功生成记忆。
- 到仓日期优先源值，否则下个周四；默认时刻暂为 00:00。
- 外部链接例外仅限 externalLinks 目录中的 lookup-workbook path，包括 WPS missing-path 类型；不跟随、不计算，输出重新构造且不含外部链接或公式。
- 图片复用原内容、校验格式与解码、逐条验证 T 列归属，输出前校验明细、图片及关系。仅 X 列纵向合并支持混箱。
- 输出为一个工作簿：“模版”承载全部业务明细，后三页保留参考字典。文件通过预验证后发布，同名不覆盖。
- 不联网建单。赤道端导入、12 位主单和图片形式仍需业务实测；本机自动化通过不能替代外部验收。
