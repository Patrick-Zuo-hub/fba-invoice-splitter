# macOS 双击启动文件设计

## 目标

在 FBA Invoice Splitter 项目文件夹根目录提供一个可双击的 macOS 启动文件，让当前开发环境无需手动输入终端命令即可启动本地 Web 工具。

本功能不是便携版：它复用项目现有的 Python 3.12 虚拟环境和已安装依赖，不打包解释器、依赖或应用安装包。

## 交付物

- 文件名：`启动 FIS.command`
- 位置：项目文件夹根目录
- 文件具有 macOS 可执行权限，可从 Finder 双击运行

## 启动行为

1. 启动文件根据自身位置定位项目根目录，不写死用户目录或 worktree 绝对路径。
2. 检查项目虚拟环境中的 Python 启动程序是否存在且可执行。
3. 设置项目源码搜索路径为 `src`，执行 `python -m fis`。
4. FIS 自动从 `8765–8775` 中选择第一个可用端口，并打开默认浏览器。
5. 如果已有健康实例，沿用现有单实例逻辑，仅打开已有页面。
6. 关闭最后一个 FIS 页面后，后台按照现有 30 秒宽限期自动退出。

## 错误处理

- 缺少或损坏 `.venv` 时，不尝试联网安装或修改环境；终端显示中文说明，提示重新配置开发环境。
- FIS 启动失败时保留程序原有中文错误信息，并返回非零退出状态。
- 路径包含空格或中文时仍能正常启动。

## 用户体验

- 双击 `.command` 会出现一个终端窗口，这是当前非便携开发版的预期行为。
- 启动成功后主要交互发生在浏览器中。
- 本阶段不制作 `.app` 外壳、不隐藏终端、不加入登录、联网服务或自动更新。

## 验证

- 自动检查启动文件存在、具有可执行权限、使用自身目录定位项目，并调用项目虚拟环境。
- 在包含空格的临时项目路径中用替代 Python 程序验证传入环境和工作目录正确。
- 从 Finder 等价的 `open` 操作实际双击启动，确认浏览器打开本机页面。
- 确认现有完整自动化测试、代码规范和类型检查不受影响。
